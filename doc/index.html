Zen Cart v2 Japanese language pack documentation


This language pack includes not only Japanese language files but although core files and database modifications adding possibility to use furigana and shipping by dimension anywhere in the cart system.

This allows use of Japanese Yamato express delivery, Nekoposu, Sagawa express delivery, Japan Post Yupack, LetterPack Lite, LetterPack Plus and EMS services. All these shipping modules files are included. Some payment and order total modules that complete shipping modules (c.o.d.) are although provided.

With this set you can use Zen Cart in Japan without having to create your own modules. Administration interface language too can be change on the fly as many plugins for which translation is included.

Original translation is the work of members of Zen-Cart.jp and few other volunteers, 10 to 20 years ago. Ideas of adding furigana and Japanese shipping modules with shipping fees based on dimension are more than ten years old but they were redesigned for Zen Cart v2.0.0 and above. As in Japan reading of name's kanjis varies a lot from one region to another, furigana are useful if not necessary on the admin side.
Japan transport methods fees are generally based on parcel size with weight limits, even fixed rate shipping have some size limits. It is why products dimensions and ability to calculate parcel dimension are necessary to provide an accurate quote.
All three major transport companies offer delivery time choice too and this option has been added too.

These extra features involve modification of some core files and database, and it is why it is not a drop in plugin, nor a one click install. Although, for a new installation, when using ZC installer, it is close to it. But when it comes to upgrading an existing site, more steps are necessary and will be covered in this documentation.

Install

Be careful that Japanese Language Pack version and English ZC versions must correspond:

ZC v1.5.8-1.5.8a --> Japanese Language Pack v1.3.4
ZC v2.0.0-2.0.1 --> Japanese Language Pack v2.0.1
ZC v2.1.0 --> Japanese Language Pack v2.1.0
ZC v2.2.0 --> Japanese Language Pack v2.2.0

If you don't respect this, database version will not be recognized correctly and database will not be updated to Japanese version.

Finally, if you have a cart already installed, you must do a complete backup including database. With files a copy is easy, but with database you must export it in an SQL file you can import again if necessary. This is a very important step! In case of troubles, it will save you lot of time and more.

New cart installation

Before starting there are few  things to do or check.

First you need a space on a server to put all your files and it must be accessible through your web browser whatever it is local or on a remote server. That means you should have a virtual host set for your domain or sub-domain to access it through HTTP or better HTTPS. If you work on a remote server, an FTP client to upload your files will be useful.
Then you must set an empty MySQL database (utf8mb4_general_ci collation) and a user with standard write-read-edit-delete rights on this database.
Please don't use too old versions of PHP and MySQL. You can check on Zen Cart site for exact requirement, but a good choice would be to use PHP 8.1 or newer and MySQL 8.xx.

Extract latest Zen Cart you have just downloaded and copy all English ZC files in your site folder. Extract Zen Cart Japanese Language Pack too and copy all content of folder 'FILES_to_INSTALL' overwriting Zen Cart original files when necessary. Don't reverse order! Do Zen Cart first then language pack.

Now you should open your browser and, in address bar, type your site address using your real domain in place of 'yoursite':
https://yoursite.com/zc_install/ (or https://yoursite.com/ and click on 'Click here' link)

Zen Cart installer will start in Japanese (you can change to English) and do some system checks. If there is no big problem with system check, you can proceed to install like a normal Zen Cart by clicking on 'Continue' button. After your first login in admin, installation is done!

Now you can go to configuration chapter to get ready for sale.

Updating an already installed English cart but still close to default setting

When installing over an existing Zen Cart 2.1.0 with no plugin that modify core files installed, it is nearly as easy as a new install but there are few points you need to check.

Best is to update ZC to latest English version then use latest Japanese Language Pack corresponding. If you don't respect this, database version will not be recognized correctly and database will not be updated to Japanese version.

First, after doing a backup of your installed cart, extract Zen Cart Japanese Language Pack and rename admin folder (in folder FILES_to_INSTALL) to the same name as your already installed ZC admin folder. Then copy everything in folder FILES_to_INSTALL to your cart, overwriting original files.

Now you should open your browser and, in address bar, type your site address using your real domain in place of 'yoursite':
https://yoursite.com/zc_install/

Zen Cart installer will start in Japanese (you can change to English) and do some system checks. If there is no big problem with system check, you can proceed to install like a normal Zen Cart by clicking on 'Upgrade' button to upgrade your database. This is very important, don't click on 'Clean install' button, it will reset your database! If 'Upgrade' button is not visible, there is a problem. It means that your database version has not been recognized or it is a wrong version, or it is already upgraded. You must sort this out and fix it to be able to do the upgrade.

After clicking on 'Upgrade' button, on next screen you will have to enter your superuser credentials, but before you must check that on the list above there is at least one option like '2.2.0 to 2.2.0210' that correspond to your version. You can then proceed as a normal install.

If all is good, you can go to configuration chapter.

Installation on an English modified cart with plugins and other custom settings or on a Japanese version cart

If you already have Zen Cart with plugins installed, you might not be able to copy this Japanese language pack files over and expect everything to work. There are two possible situations, whether installed plugins have modified Zen Cart core files or not.

If none of the Zen cart original files have been modified, if you use only encapsulated plugins for example, then it is easy. Copy files over and use the installer following instructions from precedent chapter above.

If core files have been modified (by plugins or other), there will be more steps and mainly two parts to deal with. One is files upgrade and the other is database upgrade.

First, you need to upgrade Zen Cart to the  latest version corresponding to this language pack. Please, refer to Zen Cart documentation if needed. In this case, it is better to uninstall all your plugins, especially if they are old, without forgetting to save all their settings and additional information.

For this step a good tool will make things easier and faster, something like 'phpMyAdmin' is perfect for this job. Zen Cart 'admin>Tools>Install SQL Patches' can be used too for importing SQL files.

Configuration

When upgrading database there are few settings that are done like setting Japanese Yen as default currency, adding new tax class and rate... You should check in admin that these setting are like you want them. For example, if you have more than two languages installed, you might want to use Japanese but not as default language. In this case, you must set this as you want in admin afterward.

Currency is set by default to Japanese Yen. You should check or change it at your convenience, but in any case you must update currencies exchange rates by clicking on button 'Update Exchange Rate' in 'admin>Localization>Currencies' page.

Most of specific configuration has been done at install but you still have to set your store location and postal code, define some geo-zones for your shipping modules and set these modules and payment ones too.
Please have a look at Zen Cart documentation, starting by here: https://docs.zen-cart.com/user/new_user_topics/

Modules setting

In this Language pack, shipping modules for main Japanese companies are included and you need to set them because shipping fees depends on your store location and eventually contract with shipping companies. Files to set are 'ScriptedInstaller.php' in respective plugins' 'install' folder. You need to check and adjust rates if necessary before installing plugin.
Quoting is based on arrays from these files that are saved in database when installing plugins. This is where shipping cost is set.
You will find more information through comments in class files where arrays were saved in older versions.

There is a special plugin 'Tarifs' that allows you to edit latest shipping rates saved in database from admin::Modules->Shipping Pricing. But if you want to create a completely new one, you must do it through file editing. It will be installed/copied in database at next plugin install, keeping the old one too as a backup. Do not forget to update implementation date ('imple_date'), it needs to be different/more recent than any already installed rates, or it won't be installed/used. If you use a future date, it will be installed but won't be used until this date. The rule is that when multiple rates are available for a module, the most recent with a past implementation date will be used.

You must check and eventually set the array to fit your situation. Unfortunately none of the shipping companies provide downloadable quoting tables but you can check online:
For Yamato : https://www.kuronekoyamato.co.jp/ytc/search/estimate/ichiran.html
For Sagawa : https://www.sagawa-exp.co.jp/send/fare/attention.html
For Japan Post YuPack : https://www.post.japanpost.jp/service/you_pack/charge/ichiran.html
For Japan Post overseas services : https://www.post.japanpost.jp/int/charge/list/

When plugins are installed, you still have to activate modules and adjust their settings in their respective section, depending on your needs.

If you have some question go to support forum : https://www.zen-cart.com/showthread.php?229157-V158-Japanese-language-pack

Recommended plugins

Language/Currency Links in Header

This plugin should be in any multilingual Zen Cart. Having language switch in header is very useful and practical especially on mobile displays.

ZCA Bootstrap Template for Japanese Language Pack

This is a Japanese version of this nice template adapted to this language pack. It is not yet released in Zen Cart site plugin section but can be downloaded from GitHub here. It looks great on mobiles screen.

Postcode auto fill

This plugin was designed to help customers to fill create account or new address form. It simply auto fill state, city and sometime part of street address, when customer entered is postal code. It is not a necessary feature, but avoid errors like inconsistent address where postal code and address do not correspond. Drawback is that postal code databases are big and plugin had to be separated in two parts. Importing big files in MySQL with phpMyAdmin could be problem too if PHP and MySQL are not set properly.

Image Handler 5 (Zen Cart 1.5.7+)

This plugin enhances Zen Cart images by adding a handler to offer automatic resizing of images, caching thumbnails, and more. You can upload multiple sizes of an image from the Admin image handler page.

Uninstall

First, you must delete Japanese language from Zen Cart Admin menu 'Localization>Languages'.

Then uninstall all Japanese shipping, payment and order total modules using Plugin Manager in Modules>Plugin Manager.

Delete all 'newly' added files listed in 'List of new files to copy'.

Use your backup to copy back your precedent version for all merged/replaced files listed in 'List of files to merge'.

Import SQL file 'uninstall.sql' which is in 'sql' folder of the language pack. It will remove all extra fields that have been added to database and reset to default settings that were modified at install time. Be careful that any information added in new fields created by this module will be lost.
Be aware too that default settings might not be what you want, you must checks these and adjust as you want them to be. Mainly these setting are:
Default language resets to English.
Default currency resets to USD.
Store country resets to United States.

Bonus content

You will find some language files translation for few plugins in folder '.../optional plugins/Encapsulated' for encapsulated plugins and '.../optional plugins/Non-Encapsulated' for non-encapsulated plugins. To use these, just copy files as follow:

For encapsulated plugins, copy the whole plugin folder in your cart 'zc_plugins' folder.
For non-encapsulated plugins, copy the 'includes' and 'admin' folders to your cart root, but you must rename the 'admin' folder to your actual admin folder name before.

Be aware that some plugins like Bootstrap Japanese version have customized files other than language files and you might need to merge those rather than copy them.

この言語パックには、日本語の言語ファイルだけでなく、カート システムの任意の場所でふりがなを使用したり、寸法で配送したりする機能を追加するコア ファイルとデータベースの変更も含まれています。
これにより、日本のヤマト便、ネコポス、佐川急便、日本郵便ゆうパック、レターパック ライト、レターパック プラス、および EMS サービスを利用できます。配送、支払い、および注文の合計モジュール ファイルが含まれています。
このセットにより、日本で Zen Cart を使用できるようになります。翻訳が含まれているプラ​​グインが多数あるため、管理インターフェースの言語も即座に変更できます。

最初の翻訳は、10〜20年前にZen-Cart.jpのメンバーと数人のボランティアによって行われました。
ふりがなと日本の配送モジュールを追加し、寸法に基づいた配送料を設定するというアイデアは 10 年以上前のものですが、Zen Cart v2.0.0 で再設計されました。
日本では名前の漢字の読み方が地域によって大きく異なるため、管理者側でもフリガナは非常に便利です。
日本の配送方法の料金は、荷物のサイズに基づいており、重量制限もあります。正確な見積もりを提供するには、製品の寸法と小包の寸法を計算する機能が必要 なのはそのためです。
そして、三つの主要な運送会社はすべて、配達時間の選択も提供しています。

これらの追加機能には、一部のコアファイルとデータベースの変更が伴うため、プラグインとしてそのままインストールするこ とも、ワンクリックでインストールすることもできません。ただし、新規インストールの場合は、ZCインストーラーを使用すればほぼ完了です。ただし、既存 のサイトをアップグレードする場合は、より多くの手順が必要になります。このドキュメントでは、その手順について説明します。

インストール

日本語言語パックのバージョンと英語 ZC バージョンが対応している必要があることに注意してください。

ZC v1.5.8-1.5.8a --> 日本語言語パック v1.3.4
ZC v2.0.0-2.0.1 --> 日本語言語パック v2.0.1
ZC v2.1.0 --> 日本語言語パック v2.1.
ZC v2.2.0 --> 日本語言語パック v2.2.0

これを尊重しないと、データベースのバージョンが正しく認識され ず、データベースが日本語バージョンに更新されません。

最後に、カートがすでにインストールされている場合は、データベースを含む完 全なバックアップを実行する必要があります。ファイルの場合、コピーは簡単ですが、データベースの場合は、必要に応じて再度インポート できる SQL ファイルにエクスポートする必要があります。これは非常に重要なステップです。 トラブルが発生した場合でも、時間を大幅に節約できます。詳細な説明を表示するには、以下のメニューから選択してください。

初め てのインストール

開始する前に、やるべきことや確認すべきことがいくつかあります。

まず、ローカルまたはリモート サーバー上にファイルを配置するためのスペースが必要であり、Web ブラウザからアクセスできる必要があります。つまり、HTTP またはより優れた HTTPS 経由でアクセスするには、ドメインまたはサブドメインに仮想ホストを設定する必要があります。リモート サーバーを使用する場合は、ファイルをアップロードするための FTP クライアントが便利です。
次に、空の MySQL データベース (utf8mb4_general_ci 照合) と、このデータベースに対する標準の書き込み、読み取り、編集、削除の権限を持つユーザーを設定する必要があります。
PHPとMySQLのバージョンが古すぎる場合は使用しないでください。正確な要件はZen Cartのサイトでご確認いただけますが、PHP 8.1以降とMySQL 8.xxを使用することをお勧めします。

ダウンロードした最新の Zen Cart を抽出し、すべての英語の ZC ファイルをサイト フォルダーにコピーします。Zen Cart 日本語言語パックも抽出し、必要に応じて、Zen Cart の元のファ イルを上書きして、フォルダー 'FILES_to_INSTALL' のすべてのコンテンツをコピーします。順序を逆 にしないでください！ 最初に Zen Cart を実行し、次に言語パックを実行します。

次にブラウザを開き、アドレス バーに「yoursite」の代わりに実際のドメインを使用してサイトのアドレスを入力します。
https://yoursite.com/zc_install/

Zen Cartインストーラーは日本語で起動し (英語に変更できます)、いくつかのシステム チェックを行います。システムチェックで大きな問題がなければ、「続行」ボタンをクリックして通常のZen　Cartと同様にインストールを進めてくださ い。管理者に初めてログインすると、インストールが完了します。

販売の準備をするには、設定の章に進んでください。

すでにイン ストールされている英語のカートを更新していますが、まだデフォルト設定に近いです

コア ファイルを変更するプラグインがインストールされていない既存の Zen Cart 2.1.0 に上書きインストールする場合、新規インストールとほぼ同じくらい簡単ですが、確認する必要がある点がいくつかあります。

ZC を最新の英語バージョンに更新してから、対応する最新の日本語言語パックを使用することをお勧めします。

まず、インストールしたカートのバックアップを作成した後、Zen Cart 日本語言語パックを抽出し、admin フォルダーの名前を既にインストールされている admin フォルダーと同じ名前に変更します。次に、FILES_to_INSTALL フォルダー内のすべての ものをカートにコピーし、 元のファイルを上書きします。

プラグインやその他のカスタム設定を含む英語版カートまたは日本語版カートへのインストール

すでに Zen Cart とプラグインがインストールされている場合は、この日本語言語パック ファイルをコピーしてもすべてが動作することは期待できない可能性があります。インストールされているプラグインが Zen Cart コア ファイルを変更したかどうかに関係なく、二つの状況が考えられます。

Zen Cart のオリジナル ファイルがまったく変更されていない場合、たとえばカプセル化されたプラグインのみを使用する場合は簡単です。上記の前の章の手順に従ってファイルをコピーし、インストー ラーを使用します。

構成

データベースをアップグレードするときは、デフォルト言語として日本語を設定したり、デフォルト通貨とし て日本円を設 定したり、新しい税クラスや税率を追加したりするなど、いくつかの設定を行う必要があります。設定が希望どおりであるかどうかを管理者で確認す る必要 があります。たとえば、2 つ以上の言語がインストールされている場合、日本語をデフォルトの言語として使用したくない場合があります。この場合、後で管理者で必要に応じて設定する必要があ ります。

通貨はデフォルトで日本円に設定されています。都合に合わせて確認または変更してください。いずれの場合も、「管理者 > ローカリゼーション > 通貨」ページの「為替レートの更新」ボタンをクリックして通貨の為替レートを更新する必要 があります。

特定の構成のほとんどはインストール時に行われていますが、店舗の場所と郵便番号を設定し、配送 モジュール用にいくつ かの 地域ゾーンを定義し、これらのモジュールと支払いモジュールも設定する必要があります。
ここから始まる Zen Cart のドキュメントをご覧ください（英語）： https://docs.zen-cart.com/user/new_user_topics/

モジュールの設定

この言語パックには、日本の主要企業向けの配送モジュールが含まれていますが、配送料はストアの所在地と配送会社との契約 によって異なるため、設定する必要があります。設定するファイルは、各プラグインの「インストール」フォルダ内の 「ScriptedInstaller.php」 です。プラグインをインストールする前に、必要に応じてレートを確認して調整する必要があります。
見積りは、プラグインのインストール時にデータベースに保存されるこれらのファイルの配列に基づいて行われます。ここで配送料が設定されます。
古いバージョンで配列が保存されていたクラス ファイルのコメントから、詳細情報を確認できます。

admin::Modules->Shipping Pricing からデータベースに保存されている最新の配送料を編集できる特別なプラグイン「Tarifs」があります。ただし、完全に新しいものを作成 したい場合は、ファイルの編集を 通じて行う必要があります。次のプラグインのインストール時にデータベースにインストール/コピーされ、古いものもバックアップとして保持されます。実装 日「imple_date」 を更新することを忘れないでください。すでにインストールされている料金とは異なる/新しい料金である必要があります。そうでない場合、インストール/使用されません。将 来の日付を使用すると、インストールされますが、その日付までは使用されません。ルールでは、モジュールに複数の料金が使用 可能な場合は、実装日が過去の 最新の料金が使用されます。

状況に合わせて配列を確認し、最終的に設定する必要があります。残念ながら、ダウンロード可能な見積表を提供している運送会社は存在しませんが、オンライ ンで確認することはできます。

アンインストール

まず、Zen Cart 管理メニューの「ローカリゼーション > 言語」から日本語を削除する必要 があります。

次に、「モジュール」>「プラグイン マネージャー」のプラグイン マネージャーを使用して、すべて の日本の配送、支払い、注文合計のモジュールをアンインストールします。

「コ ピーする新しいファイルのリスト」にリストされている新しく追加されたファイルをすべて削除します。

バックアップを使用して、「結 合するファイルのリスト」にリストされているすべての結合/置換され たファイルの前のバージョ ンをコピーバックします。

言語パックの「sql」フォルダーにある SQL ファイル「uninstall.sql」をインポートし ます。 データベースに追加された余分なフィールドがすべて削除され、インストール時に変更されたデフォルト設定にリセットされます。このモジュールによって作成された新しい フィールドに追加された情報はすべて失われることに注意してください。
デフォルト設定が希望どおりでない可能性があることにも注意してください。これらを確認し、希望どおりに調整する必要があります。主に次の設定があり ま す。
デフォルトの言語が英語にリセットされました。
デフォルトの通貨が米ドルにリセットされました。
購入国を米国にリセットします。

ボーナスコンテンツ

いくつかのプラグインの言語ファイル翻訳は、カプセル化されたプラグインの場合は「.../optional plugins/Encapsulated」フォルダーに、カプセル化されていないプラグインの場合は「.../optional plugins/Non-Encapsulated」フォルダーにあります。使用するには、次のようにファイルをコピーするだけです。

カプセル化されたプラグインの場合は、プラグイン フォルダー全体をカートの「zc_plugins」フォルダーにコピーします。
カプセル化されていないプラグインの場合は、「includes」フォルダと「admin」フォルダをカートのルートにコピーしますが、その前に 「admin」フォルダの名前を実際の管理フォルダ名に変更する必要があります。

Bootstrap 日本語版などの一部のプラグインには言語ファイル以外のカスタマイズされたファイルがあり、それらをコピーするのではなくマージする必要がある場合があることに注意してく ださい。
